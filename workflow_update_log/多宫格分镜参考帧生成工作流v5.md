# 多宫格分镜参考帧生成工作流（v5：Qwen-Image-Edit Camera-Aware English Prompt + Candidate Selection）

## 0. 版本定位

本版本用于将原有“多宫格分镜参考帧生成工作流 v4”升级为更适合 **Qwen-Image-Edit / Qwen-Image-Edit-2509 / Qwen-Image-Edit-2511** 的分镜参考帧生成流程。

核心升级点：

- 所有最终可复制的图像生成 prompt **必须使用英文**；
- 分镜不仅保持剧情连续性，还必须体现 **镜头多样性**；
- 每一帧必须同时满足：**story continuity + camera variation + visible-content control**；
- 新增 **candidate selection / 多候选图选择机制**：同一帧一次生成多张时，大模型必须从候选结果中选择最合适的一张，并说明理由；
- 保留 v4 中的真实文件名引用、最多两张参考图、一段式 prompt、逐帧质检、表情克制控制等规则；
- 强化 Qwen-Image-Edit 的“编辑指令”属性：prompt 应像摄影/剪辑指令，而不是文学描写。

---

## 1. 目标

用于指导大模型基于用户提供的简单 idea，逐步生成一组多宫格分镜参考帧，支持 **N=4 / 9 / 16 / 25**。

核心目标：

- 分镜剧情连续；
- 镜头变化直观，能够通过景别、机位、视角、构图重点的变化体现剧情推进；
- 人物、场景、道具保持一致性；
- 相邻帧在人物位置、动作、视线、道具状态、场景交互上有明确变化；
- 同一组 9 宫格参考图应像一段完整电影分镜，而不是同一角度下的连续插画；
- 每帧 prompt 简洁、明确、可直接复制到 Qwen-Image-Edit 使用；
- 每次最多参考两张图像；
- 最终输出的帧生成 prompt 必须是**英文一段式 prompt**，其中同时包含“how to reference images”和“what to generate in this shot”。

---

## 2. 适用范围

默认适用于：

- 动画感 / 国风 / 3D 动画风格参考帧；
- 单人物、单场景优先；
- 用户输入一个 idea 和宫格数量 N；
- 用户逐帧上传生成结果，模型先进行候选图选择或质检，再继续生成下一帧 prompt；
- 适合 Qwen-Image-Edit、Qwen-Image-Edit-2509、Qwen-Image-Edit-2511 及其多角度/图像编辑工作流。

若用户没有说明人物和场景数量，模型应自动根据 idea 给出**满足剧情的最少人物数和最少场景数**。优先单人物、单场景，除非剧情必须增加角色或场景。

---

## 3. 总体流程

### Step 1：接收用户输入

用户通常输入：

- 一个简单 idea；
- 目标宫格数 N，取值为 4 / 9 / 16 / 25；
- 可选：风格、人物数量、场景数量、特殊道具或关键动作；
- 可选：是否每帧生成多张候选图，例如 2 / 4 / 6 张。

### Step 2：输出整体策划

首次响应时，模型需要输出：

1. 视频段落概述；
2. 最少人物与场景数量安排；
3. 资源库构建 prompt；
4. N 帧分镜规划；
5. 只给出 `case_frame01.png` 的英文一段式生成 prompt。

不要一次性给出所有帧的详细生成 prompt，只给当前要生成的一帧。

### Step 3：用户生成并上传当前帧结果

用户可能上传两类结果：

#### 情况 A：单张结果

用户只上传一张当前帧结果，例如 `case_frame03.png`。

模型必须先质检：

- 合格：给出下一帧的一段式英文 prompt；
- 不合格：指出问题并给出当前帧重生成的一段式英文 prompt，不进入下一帧。

#### 情况 B：多张候选结果

用户一次生成多张当前帧候选图，例如：

- `case_frame03_A.png`
- `case_frame03_B.png`
- `case_frame03_C.png`
- `case_frame03_D.png`

或上传一张候选拼图。

模型必须先执行 **candidate selection**：

1. 判断每张候选图是否符合当前帧 prompt；
2. 从合格候选中选择最适合作为正式 `case_frame03.png` 的一张；
3. 用简短理由说明为什么选择它；
4. 如果有明显问题，也说明其他候选为什么不选；
5. 若全部不合格，则要求重生成当前帧，不进入下一帧。

## 4. 资源库构建规则

资源库用于锁定人物、场景和必要道具的一致性。

### 4.1 命名规则

- 人物图：`case_char_01.png`，如有多人物则 `case_char_02.png`
- 场景图：`case_scene_01.png`，如有多场景则 `case_scene_02.png`
- 道具图：`case_prop_01.png`
- 分镜参考帧：`case_frame01.png`、`case_frame02.png`、……、`case_frame09.png`
- 同一帧候选图：`case_frame03_A.png`、`case_frame03_B.png`、`case_frame03_C.png`
- 选中后正式命名：`case_frame03.png`

候选图只用于选择，不能直接进入最终分镜序列。最终序列中每一帧只能保留一张正式图。

### 4.2 人物参考图 prompt

人物参考图应优先锁定完整角色形象，而不是只锁定脸部。

人物参考图应锁定：

- 全身构图，人物从头到脚完整入镜；
- 人物站姿自然，四肢、鞋履、服装整体轮廓清楚可见；
- 人物朝向可为正面或 3/4 正面视角，但不要生成头像、半身像或胸像裁切；
- 脸型与整体气质；
- 发型与发饰；
- 服装款式与配色；
- 武器或配饰；
- 身材比例；
- 纯色背景或简洁背景；
- 单人物，不要场景和复杂特效。

人物参考图 prompt 必须为英文。

示例：

```text
Generate case_char_01.png: a full-body character reference sheet of a young male fantasy cultivator, standing naturally from head to toe, front or three-quarter front view, clear hairstyle, facial structure, outfit silhouette, belt, boots, and accessories, plain light background, no scene, no magic effects, no extra characters, cinematic Chinese fantasy 3D animation style.
```

### 4.3 场景参考图 prompt

场景参考图应锁定：

- 空间结构；
- 门窗位置；
- 家具陈设；
- 主要道具位置；
- 时间、天气、光源；
- 整体氛围；
- 最好不要人物。

场景参考图 prompt 必须为英文。

示例：

```text
Generate case_scene_01.png: an empty ancient Chinese fantasy interior room, clearly showing the spatial layout, wooden table, chair, window, bed, oil lamp, wall structure, floor texture, warm indoor lighting, no characters, no dramatic action, cinematic Chinese fantasy 3D animation style.
```

### 4.4 道具参考图 prompt

若剧情依赖关键道具，则单独生成道具图。道具图应锁定：

- 外形；
- 材质；
- 大小；
- 纹理；
- 是否发光或具有特殊状态；
- 纯色背景或简单台面。

道具参考图 prompt 必须为英文。

示例：

```text
Generate case_prop_01.png: a single ancient jade scroll placed on a plain light background, clearly showing its shape, carved texture, material, edge details, scale, and orientation, no hands, no character, no complex scene, cinematic Chinese fantasy 3D animation style.
```

## 5. 分镜规划规则

模型需要先规划完整 N 帧内容，但只输出当前帧的详细 prompt。

每一帧规划应包含：

- 这一帧的剧情节点；
- 这一帧承接上一帧的动作逻辑；
- 人物位置变化；
- 镜头类型和镜头变化；
- 情绪或面部表现变化：仅当剧情必须强调情绪时填写；
- 视线变化；
- 手部/身体动作变化；
- 道具状态变化；
- 场景交互痕迹；
- 当前帧承担的叙事作用；
- 与前后帧的镜头差异。

### 5.1 N 宫格节奏建议

#### 4 宫格

建立 → 触发 → 高潮 → 收束

推荐镜头节奏：

1. wide / establishing shot
2. medium shot / action trigger
3. close-up or dynamic angle / climax
4. static wide or aftermath shot / resolution

#### 9 宫格

建立 → 察觉 → 确认 → 异象 → 靠近 → 触碰 → 反应 → 高潮 → 收束

推荐镜头节奏：

1. establishing wide shot：交代人物与场景关系；
2. medium shot：人物进入动作状态；
3. close-up：人物注意到关键目标；
4. insert shot：道具、火焰、信纸、手部等关键细节；
5. over-the-shoulder or back view：建立人物视线和目标关系；
6. push-in medium shot：推进紧张感；
7. reaction close-up：人物反应；
8. dynamic low-angle / high-angle shot：高潮；
9. static wide shot or aftermath shot：收束。

#### 16 / 25 宫格

在 9 宫格结构上拆得更细，但每一帧仍只承担一个明确动作节点。必须避免连续多帧镜头、构图和画面重点过于相似。

## 6. 镜头多样性规则

### 6.1 每一帧必须至少变化一项

相邻帧之间必须至少变化以下一项：

1. **Shot size**：wide shot / full-body shot / medium shot / close-up / insert shot；
2. **Camera angle**：eye-level / low angle / high angle / overhead / over-the-shoulder / back view；
3. **Visible focus**：whole environment / upper body / face / hand / prop / action contact point；
4. **Composition emphasis**：center composition / foreground-background relation / subject-object relation / empty space / aftermath trace；
5. **Camera movement implication**：push-in / pull-back / rotate slightly / move higher / move lower / move behind the subject。

如果相邻两帧只有人物动作变化，但景别、机位、主体比例、画面重点都基本相同，则判定为镜头重复，应重写 prompt 或重生成。

### 6.2 稳定镜头词库

优先使用以下相对稳定的镜头类型：

```text
wide shot
full-body shot
medium shot
close-up
insert shot
eye-level view
low-angle view
high-angle view
overhead view
over-the-shoulder view
back view
```

谨慎使用以下镜头词：

```text
extreme Dutch angle
extreme worm's-eye view
complex 180-degree camera orbit
rapid camera roll
abstract POV
```

这些镜头可能导致人物或场景结构崩坏，除非用户明确需要。

### 6.3 镜头指令不能只写术语

“close-up / medium shot / low angle / overhead”只能作为辅助。每帧 prompt 必须继续写清楚：

- 当前画面主体是什么；
- 主体占据画面的大致比例；
- 哪些身体部位或道具必须清楚；
- 当前动作接触点在哪里；
- 视线指向哪里；
- 哪些场景元素只是辅助背景。

核心原则：

> 用镜头术语指定方向，用可见内容锁定结果。

## 7. Qwen-Image-Edit Camera Prompt 规则

### 7.1 Camera Layer

每一帧 prompt 中必须包含一个明确的 camera layer。推荐写法：

```text
camera: [shot size], [camera angle], [composition focus], [optional motion or viewpoint change]
```

示例：

```text
camera: wide shot, eye-level view, centered composition, static establishing frame
```

```text
camera: close-up, low-angle view, the face and upper chest fill most of the frame, slight push-in feeling
```

```text
camera: insert shot, overhead view, the hand and glowing scroll fill most of the frame
```

```text
camera: over-the-shoulder view from behind the character, foreground shoulder and hair visible, the glowing object is the focus
```

### 7.2 不要过度依赖精确角度数字

可以写：

```text
change the view to a slightly lower camera position and tilt upward
```

不优先写：

```text
rotate the camera exactly 37 degrees
```

原因：在实际工作流中，精确数字角度不一定稳定，模型更容易响应“从哪里看、画面里应该看见什么”。

### 7.3 镜头变化写法

推荐：

```text
change the view to a lower vantage point, with the camera tilted upward toward the character and the flame
```

```text
change the view to an overhead insert shot, focusing on the hand touching the glowing paper
```

```text
change the view to behind the character's right shoulder, keeping the shoulder and hair in the foreground and the target object in clear focus
```

不推荐：

```text
make it cinematic
```

```text
change the angle dramatically
```

```text
same as previous but more intense
```

## 8. 每帧参考图规则

每帧最多参考两张图。

### 8.1 必须使用真实文件名引用参考图

最终 prompt 中引用参考图时，必须写用户资源库中的真实文件名，例如：

- `case_frame01.png`
- `case_char_01.png`
- `case_scene_01.png`
- `case_prop_01.png`

不能写界面自动编号或临时称呼，例如：

- `Image 0`
- `Image 1`
- `the previous image`
- `the last frame`
- `the reference image`
- `this image`
- `the previous version`

注意：英文 prompt 中也不能写 `the previous image`。必须写真实文件名。

### 8.2 每张参考图必须说明参考什么

正确英文写法：

```text
Use case_frame04.png for the character position, body direction, and the current glowing flame state.
```

```text
Use case_char_01.png for the character identity, facial structure, hairstyle, outfit, belt, boots, and accessories.
```

```text
Use case_scene_01.png for the room layout, table position, window, furniture, lighting direction, and overall atmosphere.
```

错误写法：

```text
Use the previous image.
```

```text
Refer to Image 0.
```

```text
Same as before.
```

### 8.3 常用参考组合

- `case_frame01.png`：`case_char_01.png` + `case_scene_01.png`
- 人物身份连续性帧：当前正式前一帧真实文件名 + `case_char_01.png`
- 场景动作帧：当前正式前一帧真实文件名 + `case_scene_01.png`
- 道具特写帧：当前正式前一帧真实文件名 + `case_prop_01.png`
- 空镜收束帧：`case_scene_01.png` + 当前正式前一帧真实文件名

## 9. 英文一段式 Prompt 输出规则

### 9.1 最终给用户复制的 prompt 必须是英文一段式

每次输出当前帧或下一帧生成 prompt 时，最终可复制部分必须是**一个完整英文自然段**，不能拆成“reference / camera / description / constraints”多个段落，也不能用项目符号拆开。

这个英文一段式 prompt 内必须同时包含：

1. 文件名；
2. 参考哪些图；
3. 每张图分别参考什么；
4. camera layer；
5. 当前帧生成内容；
6. 当前镜头下应该清楚看到什么；
7. 动作、视线、道具状态；
8. 必要约束；
9. 风格句。

### 9.2 推荐一段式结构

```text
Generate case_frame02.png: Use case_frame01.png for the character position, body direction, and the current flame state, and use case_char_01.png for the character identity, facial structure, hairstyle, outfit, and accessories. Camera: medium shot, eye-level view, centered composition, with the character and the floating flame both clearly visible. The main subject is the character standing on the lava stone platform, raising both hands in front of his chest to form a spell gesture, while his gaze is fixed on the floating blue-green flame in front of him. Clearly show the distance between his hands and the flame, the stone platform under his feet, and the lava cave background as secondary context. Keep the character identity, outfit, flame color, lighting direction, and environment unchanged. Do not add new characters, weapons, or extra fire sources. Cinematic Chinese fantasy 3D animation style.
```

### 9.3 Prompt 不要过长

原则：

- 只描述当前镜头必须看见的内容；
- 不要把人物设定、场景设定、世界观全部重复一遍；
- 如果某些细节仅用于身份一致性，写在参考图说明里即可，不要在画面描述里反复展开；
- 避免堆砌形容词。

## 10. 常见镜头的英文可见内容模板

以下模板用于指导 prompt 中如何描述“镜头下应该看到什么”。实际输出时必须合并成一个英文自然段。

### 10.1 Establishing wide shot / 建立镜头

用途：交代空间关系。

应描述：

- 人物全身；
- 场景完整布局；
- 人物与关键道具的位置关系；
- 不强调细小面部表情。

英文模板：

```text
Camera: wide shot, eye-level view, static establishing frame. The main subject is the full-body character within the complete environment, clearly showing the spatial relationship between the character, the key object, and the surrounding scene.
```

### 10.2 Medium action shot / 中距离动作镜头

用途：表现人物动作推进，同时保留环境关系。

英文模板：

```text
Camera: medium shot, eye-level view, the character from head to knees fills the center of the frame. Clearly show the body movement, hand position, gaze direction, and the key object nearby, while keeping the environment as secondary context.
```

### 10.3 Close-up / 面部近景

用途：锁定人物身份、视线、反应。

自然表情模板：

```text
Camera: close-up, eye-level view, the face and upper chest fill most of the frame. Clearly show the facial structure, hairstyle, collar, shoulder details, and the gaze directed toward the key object, without exaggerating the facial expression.
```

强情绪模板：

```text
Camera: close-up, eye-level view, the face fills most of the frame. Clearly show widened eyes, tense gaze, and an open mouth, with the background weakened.
```

### 10.4 Insert shot / 道具或手部特写

用途：表现触碰、拿取、按压、拔剑、施法、火焰状态变化。

英文模板：

```text
Camera: insert shot, overhead or slightly high-angle view, the hand and the key object fill most of the frame. Clearly show the fingertips, knuckles, object surface, contact point, and the glow or texture change around the contact area.
```

### 10.5 Over-the-shoulder shot / 过肩镜头

用途：强调人物正在看什么。

英文模板：

```text
Camera: over-the-shoulder view from behind the character. Keep the shoulder, back of the head, and part of the hair in the foreground, while the key object in front of the character is the main focus.
```

### 10.6 Back view / 背面镜头

用途：表现人物面向某物、凝视、压抑、孤独或仪式感。

英文模板：

```text
Camera: back view, medium-wide shot. Clearly show the back of the character, hairstyle, shoulder line, back clothing texture, and the key object positioned directly in front of the character.
```

### 10.7 Overhead view / 俯视镜头

用途：表现桌面布局、空间关系、多人/物体方位。

英文模板：

```text
Camera: overhead view, high-angle composition. Clearly show the layout of the table, key objects, and the character entering the frame from one side, with the top of the head, shoulder, and reaching hand visible if the character appears.
```

### 10.8 Low-angle dynamic shot / 仰拍动态镜头

用途：高潮、力量感、压迫感。

英文模板：

```text
Camera: low-angle view, dynamic medium shot, the camera is positioned below the character and tilted upward. Clearly show the character's body posture, raised arm, key object or energy above, and the background scale behind them.
```

### 10.9 Static aftermath shot / 收束空镜或余波镜头

用途：结束、余波、环境变化。

英文模板：

```text
Camera: static wide shot, calm aftermath composition. No character appears in the frame. Clearly show the environment inheriting the changed object state, such as a pushed chair, fading glow, scattered particles, or a still-open scroll.
```

## 11. 表情控制规则

面部表情不是每帧 prompt 的必填项。只有当剧情明确需要表现恐惧、愤怒、哭泣、震惊、疼痛等强情绪时，才描述面部表情。

如果目标是让人物表情自然、克制、稳定、不夸张，则不要写具体面部表情词，尤其不要写：

```text
painful expression
slightly painful
terrified
twisted face
angry grimace
subtle suffering
```

此时只描述人物身份、发型、服装、姿态、手部动作、视线方向、道具状态和场景关系即可。

推荐写法：

```text
Clearly show his gaze fixed on the floating flame, without emphasizing any exaggerated facial expression.
```

不推荐写法：

```text
Clearly show his slightly painful expression.
```

## 12. Candidate Selection：多候选图选择机制

### 12.1 触发条件

当用户一次生成并上传同一帧的多张候选图时，模型必须先执行候选图选择，不得直接输出下一帧 prompt。

候选图可能是：

- 多张单独图片；
- 一张 2×2 / 3×3 候选拼图；
- 用户口头说明“这是同一 prompt 生成的几张结果”。

### 12.2 选择目标

选择的不是“最好看”的图，而是**最适合作为当前正式分镜帧并能承接下一帧的图**。

优先级：

1. 当前帧 prompt 符合度；
2. 人物身份、服装、发型、道具一致性；
3. 场景结构、光源、空间逻辑连续性；
4. 镜头类型是否符合当前 shot plan；
5. 与上一帧是否有清晰剧情推进；
6. 是否为后续帧提供稳定参考；
7. 图像质量与可用性；
8. 是否避免新增无关人物、道具或错误细节。

### 12.3 候选图评分表

模型可以使用内部评分，但给用户输出时应简洁。

评分维度：

| 维度 | 说明 |
|---|---|
| Prompt Match | 是否符合当前英文 prompt |
| Character Consistency | 人物身份、脸、发型、服装是否一致 |
| Scene Continuity | 场景、光源、物体位置是否继承 |
| Camera Accuracy | 镜头类型、景别、机位是否正确 |
| Story Progression | 是否体现当前剧情节点 |
| Future Usability | 是否适合作为下一帧参考 |
| Visual Quality | 是否有明显畸形、模糊、错误元素 |

### 12.4 选择规则

- 如果有一张明显优于其他候选，直接选择；
- 如果两张接近，优先选 **连续性更强** 的，而不是画面更炫的；
- 如果当前帧是关键动作帧，优先选动作逻辑清楚的；
- 如果当前帧是参考承接帧，优先选人物和场景稳定的；
- 如果当前帧是镜头变化帧，优先选镜头类型最准确的；
- 如果全部候选都不合格，不选择任何一张，要求重生成。

### 12.5 候选图选择输出模板

#### 有合格候选

```md
推荐选择：case_frame03_B.png，并将其命名为正式的 case_frame03.png。

理由：B 的人物身份、服装和场景连续性最稳定，镜头也最接近当前要求的 over-the-shoulder view；A 的人物位置偏移较大，C 的关键道具不清楚，D 虽然画面好看但镜头仍接近上一帧，分镜变化不足。下一帧可以基于 case_frame03.png 继续推进。
```

随后给出下一帧英文一段式 prompt。

#### 全部不合格

```md
这一组候选图都不建议选为 case_frame03.png：共同问题是镜头仍然接近上一帧，关键道具没有成为画面主体，人物位置也没有承接 case_frame02.png。建议重生成当前帧。

Regenerate case_frame03.png: ...
```

### 12.6 候选图选择后的正式命名

选中候选后，必须明确告诉用户：

```text
Please rename the selected candidate as case_frame03.png before generating the next frame.
```

不要让 `case_frame03_B.png` 直接作为后续 prompt 中的正式参考名，除非用户明确不想重命名。

## 13. 逐帧质检规则

用户上传当前帧后，模型必须先检查质量。若上传多张候选图，先执行候选选择，再质检选中图是否可用。

### 13.1 人物连续性

检查：

- 发型是否一致；
- 服装是否一致；
- 武器/饰品是否一致；
- 面部风格是否一致；
- 人物左右朝向是否合理；
- 是否出现多余人物或错误角色。

### 13.2 场景连续性

检查：

- 桌子、窗户、门、床榻、椅子位置是否稳定；
- 光线来源是否稳定；
- 天气是否一致；
- 时间感是否一致；
- 场景中的已变化物体是否被继承；
- 关键道具是否保持同一形态或符合剧情变化。

### 13.3 动作连续性

检查：

- 是否承接上一帧；
- 是否出现无缘由跳变；
- 身体重心是否合理；
- 手与道具的接触/脱离是否合理；
- 人与家具的位置是否合理；
- 动作是否清楚，不只是姿势变化。

### 13.4 镜头连续性与多样性

检查：

- 当前帧是否符合计划中的 shot type；
- 当前帧是否与上一帧有明确镜头差异；
- 当前帧是否通过“画面中应出现什么”体现了该镜头；
- 是否出现镜头术语与实际画面不一致；
- 当前帧是否为下一帧提供足够稳定的参考。

### 13.5 物理交互逻辑

检查：

- 人贴桌后撤，椅子是否应被推开；
- 手触碰道具后撤，下一帧手是否应离开道具；
- 拔剑前是否先握住剑柄；
- 剑出鞘后是否保持出鞘；
- 被碰到、推开、点亮、打开的物体是否继承状态；
- 雨、雪、烟、光等环境元素是否符合场景逻辑。

---

## 14. 重生成判定

出现以下任一情况，应要求当前帧重生成：

- 场景逻辑错误，如雨下到室内；
- 人物明显漂移；
- 与上一帧差异太小；
- 镜头主体不符合要求；
- 镜头类型错误，例如要求 close-up 却仍是 full-body shot；
- 镜头多样性不足，连续多帧像同一机位；
- 动作没有推进；
- 动作顺序错误；
- 物理交互不合理；
- 新增无关人物或道具；
- 场景状态没有继承；
- 候选图中没有任何一张适合作为后续参考。

重生成时仍然必须输出英文一段式 prompt。

---

## 15. 输出风格

模型输出应：

- 简洁；
- 执行型；
- 少解释；
- prompt 可直接复制；
- 不写冗长文学描写；
- 不堆砌无关形容词；
- 用“camera layer + visible content”驱动镜头效果；
- 给用户的解释可以是中文，但最终可复制 prompt 必须是英文。

---


## 17. 核心执行口令

写每一帧 prompt 前，模型必须先在内部确认：

1. What is the story beat of this frame?
2. What camera change happens compared with the previous frame?
3. What should the viewer clearly see in this shot?
4. Which two real filenames should be referenced?
5. Which details should not be described to avoid distraction?
6. Does this frame provide a stable reference for the next frame?

最终输出必须是英文一段式 prompt。

---

## 18. 最小执行原则

当不确定镜头该怎么写时，不要增加复杂镜头术语，而是回到以下结构：

```text
Generate case_frame0x.png: Use [real filename] for [specific reference target], and use [real filename] for [specific reference target]. Camera: [shot size], [camera angle], [composition focus]. The main subject is [visible subject]. Clearly show [visible details], [action/contact point], [gaze direction], and [object state]. Keep [identity/lighting/environment] unchanged. Do not [unwanted changes]. Cinematic Chinese fantasy 3D animation style.
```

---

## 19. 一句话总结

本工作流的核心不是让每一帧都“更漂亮”，而是让每一帧都能同时完成三件事：

```text
continue the story, change the camera, and preserve consistency.
```
