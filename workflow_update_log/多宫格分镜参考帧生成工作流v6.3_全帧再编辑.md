# 多宫格分镜参考帧生成工作流（v6.3：先稳定九宫格，再全帧再编辑 + 连续性修复 + 电影级镜头统一）

## 0. 版本定位

本版本是在 v6.2 的基础上继续升级第二阶段流程，用于解决“基础帧稳定但电影感不足”“部分基础帧存在小瑕疵”“只选择少数帧做镜头变换导致最终九宫格风格不均衡”等问题。

v6.2 的核心逻辑是：

```text
第一阶段先生成稳定剧情九宫格；
第二阶段由多模态大模型选择部分基础帧进行镜头变换；
未变换帧直接保留为最终帧。
```

v6.3 将第二阶段进一步升级为：

```text
第一阶段：生成稳定 base frames，用来锁定剧情连续性、人物一致性、场景一致性和关键状态；
第二阶段：对所有 base frames 逐帧进行再编辑，每一帧都生成对应的 edited frame；
最终九宫格统一使用 edited frames，而不是部分 base frames + 部分 transformed frames 的混合结果。
```

核心变化可以概括为：

```text
v6.2: 基础帧负责连续性，部分派生镜头负责电影感。
v6.3: 基础帧仍负责连续性，但所有基础帧都要进入再编辑阶段；第二阶段既负责电影级镜头多样性，也负责修复基础帧中的轻微瑕疵。
```

v6.3 保留 v6.2 的三条硬性规则：

1. **基础帧必须显式写明 Subject–Camera Relation**：不能只写人物面向桌子、玉简、石台、门口等目标物，还必须写人物相对镜头是背对、正对、侧对、三分之二背对还是三分之二正对。
2. **基础帧采用最小参考原则**：如果当前帧只是同一镜头尺度、同一人物可见面下的剧情推进，优先只参考上一张基础帧；不要机械地重复引用 `case_char_01.png`，避免模型重新展示角色正脸、拉近镜头或改变构图。
3. **开场帧采用朝向中立选择原则**：`case_base_frame01.png` 不默认背影、正面或侧面。模型必须根据开场镜头意图选择人物与镜头关系。

v6.3 新增三条第二阶段硬性规则：

1. **全帧再编辑原则**：第二阶段不再判断“哪些帧是否需要变换”，而是所有 `case_base_frame0x.png` 都必须生成对应的 `case_edit_frame0x.png`。
2. **编辑策略逐帧选择原则**：多模态大模型不再选择“是否编辑”，而是为每一帧选择“如何编辑”：保持构图并修瑕、轻微重构、电影化重构、特写/插入镜头、俯视/低角度/过肩镜头、氛围增强等。
3. **连续性优先的再编辑原则**：再编辑必须继承 base frame 的剧情状态、人物位置、道具状态和场景锚点。只有基础帧存在轻微瑕疵时，才允许在不改变剧情节点的前提下修正。

## 1. 核心目标

用于指导大模型基于用户 idea 生成 **N=4 / 9 / 16 / 25** 的多宫格参考帧，其中 9 宫格是默认推荐形态。

v6.3 的目标分为两层。

### 1.1 第一阶段目标：稳定剧情骨架

第一阶段仍然生成 `case_base_frame01.png` 到 `case_base_frame09.png`。

这一阶段的目标不是电影镜头，而是稳定剧情：

- 剧情连续：每一帧是一个明确的剧情状态节点；
- 状态清楚：人物动作、视线、道具状态、场景变化有明确承接；
- 角色稳定：人物身份、发型、服装、体型、配饰保持一致；
- 场景稳定：空间结构、光源、关键参考物、地面纹理保持一致；
- 位置稳定：人物和道具必须使用场景内可见锚点定位；
- 镜头稳定：每一帧只使用明确的 `wide shot` 或明确的 `medium shot`；
- 朝向稳定：每一帧必须明确人物与目标物关系，以及人物与镜头关系；
- 开场中立：`case_base_frame01.png` 不默认背影开局，必须根据开场镜头意图选择正面、背面、侧面或三分之二视角；
- 参考稳定：每张基础帧都应适合作为第二阶段再编辑的输入。

### 1.2 第二阶段目标：全帧再编辑

第二阶段不再只处理部分帧，而是对每一张基础帧都进行一次再编辑。

第二阶段的目标包括：

- 在 base frame 的基础上保持剧情连续性；
- 对所有帧统一进行电影级视觉增强；
- 为每一帧选择合适的镜头策略；
- 增加最终九宫格的镜头多样性；
- 修复 base frame 中可通过编辑解决的小瑕疵；
- 统一角色、场景、光照、氛围和风格；
- 输出完整的 `case_edit_frame01.png` 到 `case_edit_frame09.png`；
- 最终九宫格默认使用 edited frames。

## 2. 总体流程

### Step 1：接收用户输入

用户通常输入：

- 一个简单 idea；
- 宫格数量 N，通常为 4 / 9 / 16 / 25；
- 可选：风格、人物数量、场景数量、关键道具、关键动作；
- 可选：每帧是否一次生成多张候选图；
- 可选：是否需要第二阶段全帧再编辑。

若用户没有特别说明，v6.3 默认采用“两阶段 + 全帧再编辑”流程。

### Step 2：整体策划

首次响应时，模型输出：

1. 视频概述；
2. 最少人物、场景、道具数量；
3. 资源库构建 prompt；
4. 第一阶段基础剧情帧规划；
5. `case_base_frame01.png` 的开场镜头意图与人物朝向选择理由；
6. 只给出 `case_base_frame01.png` 的英文一段式 prompt。

不要一次性给出所有基础帧的详细 prompt。只给当前要生成的一帧。

### Step 3：第一阶段逐帧生成基础九宫格

逐帧生成：

```text
case_base_frame01.png
case_base_frame02.png
...
case_base_frame09.png
```

每一帧必须先确定唯一镜头类型：

```text
wide shot
```

或：

```text
medium shot
```

最终 prompt 里只能写一个确定镜头，不能写 `wide shot or medium shot`，不能写 `wide / medium shot`，不能写 `either wide shot or medium shot`，也不能使用任何含糊的选择式表达。

基础帧阶段不主动使用：

- close-up；
- insert shot；
- overhead view；
- over-the-shoulder view；
- Dutch angle；
- extreme low-angle view；
- complex camera rotation；
- heavy foreground blocking。

除非用户明确要求第一阶段就使用特殊镜头，否则基础帧只承担剧情状态表达。

### Step 4：第一阶段候选图选择

如果用户一次上传同一基础帧的多张候选图，模型必须先选择最适合作为基础剧情帧的图，不得直接进入下一帧。

基础帧候选选择重点不是“画面最炫”，而是：

1. 是否符合当前剧情节点；
2. 是否稳定继承角色身份；
3. 是否稳定继承场景结构；
4. 是否准确使用位置锚点；
5. 是否清楚表现人物与目标物关系；
6. 是否清楚表现人物与镜头关系；
7. 是否没有复杂镜头导致的信息缺失；
8. 是否适合作为后续再编辑输入。

### Step 5：完成基础九宫格后进行整体质检

当 `case_base_frame01.png` 到 `case_base_frame09.png` 全部完成后，模型需要进行整体检查：

- 九张图的人物是否一致；
- 场景是否一致；
- 关键道具是否连续；
- 位置推进是否清楚；
- 剧情是否能从第一帧读到第九帧；
- 是否存在某张基础帧严重错误，不能作为再编辑输入；
- 哪些基础帧只有轻微瑕疵，可以通过第二阶段修复；
- 哪些基础帧需要在进入第二阶段前先重生成。

只有基础九宫格通过“基础可编辑性检查”后，才进入第二阶段。

### Step 6：第二阶段全帧再编辑规划

第二阶段必须查看完整基础九宫格，并为每一帧生成编辑计划。

模型不再判断：

```text
哪些帧需要变换，哪些帧不需要变换。
```

而是判断：

```text
每一帧应该采用什么编辑策略。
```

每一张基础帧都必须对应一张编辑帧：

```text
case_base_frame01.png → case_edit_frame01.png
case_base_frame02.png → case_edit_frame02.png
...
case_base_frame09.png → case_edit_frame09.png
```

### Step 7：逐帧生成 edited frames

对每一张基础帧生成再编辑版本：

```text
case_edit_frame01.png
case_edit_frame02.png
...
case_edit_frame09.png
```

再编辑 prompt 必须以对应 `case_base_frame0x.png` 为主参考。

如果只是修瑕或强化氛围，可以保持原镜头类型；如果当前帧适合电影化表达，可以进行镜头重构。

### Step 8：第二阶段候选图选择

如果用户一次上传同一 edited frame 的多个候选图，模型必须选择最适合作为最终分镜帧的候选图。

此时选择标准同时考虑：

- 是否保留 base frame 的剧情状态；
- 是否修复或改善 base frame 的瑕疵；
- 是否增强了电影感；
- 是否与前后 edited frames 保持连续；
- 是否适合作为最终九宫格的一帧。

### Step 9：最终分镜整理

最终分镜默认使用：

```text
case_edit_frame01.png
case_edit_frame02.png
...
case_edit_frame09.png
```

可以统一重命名为：

```text
case_final_frame01.png
case_final_frame02.png
...
case_final_frame09.png
```

标准情况下，最终帧不再直接使用 raw base frames。  
只有当某一帧再编辑反复失败，并且 base frame 本身已经足够优秀时，才允许临时保留 base frame 作为最终帧，但这属于异常情况，需要说明原因。

## 3. 命名规则

### 3.1 资源库命名

- 人物参考图：`case_char_01.png`
- 多人物参考图：`case_char_02.png`、`case_char_03.png`
- 场景参考图：`case_scene_01.png`
- 多场景参考图：`case_scene_02.png`
- 道具参考图：`case_prop_01.png`

### 3.2 第一阶段基础帧命名

- 基础剧情帧：`case_base_frame01.png`、`case_base_frame02.png`、……、`case_base_frame09.png`
- 同一基础帧候选图：`case_base_frame03_A.png`、`case_base_frame03_B.png`、`case_base_frame03_C.png`
- 选中候选后必须重命名为正式基础帧，例如：`case_base_frame03_B.png` → `case_base_frame03.png`

### 3.3 第二阶段全帧再编辑命名

- 全帧再编辑结果：`case_edit_frame01.png`、`case_edit_frame02.png`、……、`case_edit_frame09.png`
- 同一编辑帧候选图：`case_edit_frame04_A.png`、`case_edit_frame04_B.png`
- 选中候选后必须重命名为正式编辑帧，例如：`case_edit_frame04_B.png` → `case_edit_frame04.png`

v6.3 中不再推荐使用 `case_shot_frame0x.png` 作为主命名。  
如果历史项目中已经使用 `case_shot_frame0x.png`，可以理解为 `case_edit_frame0x.png` 的旧命名。

### 3.4 最终分镜命名

- 最终分镜帧：`case_final_frame01.png`、`case_final_frame02.png`、……、`case_final_frame09.png`

最终 prompt 中禁止写：

```text
the previous image
Image 0
reference image
this image
last frame
the selected image
```

必须写真实文件名。

## 4. 资源库构建规则

资源库构建规则与 v6.2 保持一致。

### 4.1 人物参考图

人物参考图用于锁定完整角色形象，不是只锁定脸部。

应包含：

- 全身入镜；
- 正面或 3/4 正面视角；
- 发型、发饰、脸型、服装轮廓、腰带、袖口、靴子、配饰清楚；
- 纯色或简洁背景；
- 不要场景、复杂特效、额外人物。

示例：

```text
Generate case_char_01.png: a full-body character reference sheet of Wang Lin, a young male Chinese fantasy cultivator with black hair tied in a high topknot, wearing a dark blue robe with silver embroidery, a waist belt, long sleeves, black boots, and small jade accessories, standing naturally from head to toe on a plain light background, front three-quarter view, clear facial structure, hairstyle, outfit silhouette, sleeve details, belt, boots, no scene, no magic effects, no extra characters, cinematic Chinese fantasy 3D animation style.
```

### 4.2 场景参考图

场景参考图不仅要锁定氛围，还要主动生成可复用视觉锚点。

应包含：

- 空间结构；
- 关键地标或家具；
- 地面纹理；
- 台阶、门框、窗户、石柱、桌角、桌面边缘、圆形纹路等可定位元素；
- 光源方向；
- 最好不要人物。

示例：

```text
Generate case_scene_01.png: an empty ancient lava cave interior, clearly showing the spatial layout with a central circular stone platform, multi-ringed circular texture on the platform surface, surrounding molten lava flows, platform edge stones, rocky walls, cave opening, stalactites, and dim orange ambient lighting from the lava, no characters, no props, pure environment reference, cinematic Chinese fantasy 3D animation style.
```

### 4.3 道具参考图

若剧情依赖关键道具，则单独生成道具图。

道具参考图应锁定：

- 外形；
- 材质；
- 大小比例；
- 纹理；
- 发光状态；
- 朝向；
- 纯色背景或简单台面。

## 5. 第一阶段：稳定剧情九宫格规划规则

第一阶段的九宫格不是电影镜头集合，而是剧情状态集合。

每一帧都要回答：

1. 当前剧情节点是什么？
2. 人物处于什么最终状态？
3. 人物和目标物的关系是什么？
4. 人物和镜头的关系是什么：正面、背面、侧面、三分之二正面还是三分之二背面？
5. 如果这是 `case_base_frame01.png`，开场镜头意图是什么：介绍人物、介绍空间、人物进入、道具引入还是悬念建立？
6. 如果这是 `case_base_frame01.png`，当前朝向选择是否服务于开场镜头意图，而不是默认背影？
7. 人物在场景中的落点是什么？
8. 关键道具处于什么状态？
9. 当前帧应该使用 `wide shot` 还是 `medium shot`？
10. 当前帧是否需要重新引用 `case_char_01.png`，还是只参考上一帧更稳定？
11. 这一帧是否适合作为第二阶段再编辑输入？

### 5.1 基础帧镜头硬性规则

基础帧阶段每一帧必须先在规划表中确定唯一镜头类型：

```text
Base camera: wide shot
```

或：

```text
Base camera: medium shot
```

最终 prompt 中必须写一个确定的 camera layer，例如：

```text
Camera: wide shot, eye-level view, static composition, showing the full body of the character and the complete spatial relationship between the stone platform, the lava flow, and the cave wall.
```

或：

```text
Camera: medium shot, eye-level view, stable centered composition, showing the character from head to knees with the nearby table edge, scroll, and window frame still visible as spatial anchors.
```

禁止写：

```text
Camera: wide shot or medium shot.
```

```text
Camera: wide / medium shot.
```

```text
Camera: either a wide shot or a medium shot.
```

```text
Camera: use a suitable wide or medium view.
```

### 5.2 基础帧人物–镜头关系硬性规则

基础帧阶段不允许只通过剧情语义暗示人物朝向。每一帧 prompt 必须同时写明：

1. **Subject–Object Relation**：人物面向哪个目标物或正在与哪个目标物交互；
2. **Subject–Camera Relation**：镜头看到的是人物正面、背面、侧面、三分之二正面还是三分之二背面。

例如，人物站在桌前看玉简时，不能只写：

```text
facing the tabletop where the jade slip rests
```

因为这句话只能说明人物面对玉简，不能防止模型把镜头绕到人物正面。应写成：

```text
facing the tabletop where the jade slip rests, with his back facing the camera
```

或：

```text
full-body back view of the cultivator; the table is directly in front of him and his back faces the camera
```

核心原则：

```text
人物面向目标物 ≠ 人物背对镜头。Subject–Object Relation 和 Subject–Camera Relation 必须分开判断，并且都写进 prompt。
```

### 5.3 开场朝向中立选择规则

`case_base_frame01.png` 没有默认朝向偏好。基础帧必须显式写明人物与镜头关系，但“显式写明”不等于“默认背影”。

#### 适合使用 back view / three-quarter back view 的开场

当开场的重点是让观众跟随人物进入未知空间、观察远处目标物、建立空间纵深或制造探索感时，可以使用背影或三分之二背影。

#### 适合使用 front view / three-quarter front view 的开场

当开场的重点是介绍人物身份、气质、服装、表情、正面轮廓，或者需要同时展示桌面道具、室内氛围和人物反应时，应使用正面或三分之二正面。

#### 适合使用 side view / three-quarter side view 的开场

当开场的重点是人物跨过门槛、推门进入、从走廊进入房间、沿桌边移动，或者需要同时显示人物运动方向和场景入口时，可以使用侧面或三分之二侧面。

核心原则：

```text
开场帧必须明确朝向，但朝向选择必须服务于开场叙事功能；背影只是可选方案，不是默认方案。
```

### 5.4 全景与中景的选择标准

#### 使用 wide shot 的情况

当当前帧需要强调以下内容时，选择 `wide shot`：

- 人物与完整场景的空间关系；
- 人物从一个场景锚点移动到另一个场景锚点；
- 关键道具和人物距离关系；
- 多人物站位；
- 场景状态变化；
- 开场或收束；
- 需要为后续帧提供完整稳定参考。

#### 使用 medium shot 的情况

当当前帧需要强调以下内容时，选择 `medium shot`：

- 人物上半身动作；
- 手部动作但仍需看到身体和场景锚点；
- 人物与近处道具互动；
- 人物视线和姿态；
- 不需要完整场景，但仍需要保留关键空间锚点。

### 5.5 基础帧阶段不追求镜头多样性

基础帧之间可以有少量宽窄变化，但不以“每帧镜头不同”为目标。

允许：

- wide shot → wide shot；
- wide shot → medium shot；
- medium shot → medium shot；
- medium shot → wide shot。

不允许为了镜头多样性强行加入：

- 特写；
- 局部插入；
- 过肩；
- 俯视；
- 背面遮挡；
- 大幅旋转；
- 极端低角度；
- 大面积前景遮挡。

基础帧首先要稳定，其次才考虑基础层面的构图变化。

## 6. 第一阶段 Prompt 规则

基础帧 prompt 必须是英文一段式，且必须包含：

1. 文件名；
2. 参考哪些真实文件名；
3. 每张图分别参考什么；
4. 确定的基础镜头类型；
5. 位置锚点；
6. 人物与目标物关系；
7. 人物与镜头关系；
8. 如果是 `case_base_frame01.png`，规划表必须给出开场镜头意图与朝向选择理由，最终 prompt 中只需要明确写出选定朝向；
9. 当前剧情状态；
10. 道具或环境状态；
11. 不改变角色和场景的约束；
12. 风格句。

### 6.1 基础帧最小参考原则

第一阶段基础帧生成不应机械地使用“上一帧 + 角色参考图”的固定组合。基础帧的目标是稳定继承剧情、场景、镜头尺度和人物可见面，因此参考图应尽量少、尽量直接。

#### 优先只参考上一张基础帧的情况

如果当前帧只是以下变化，优先只参考上一张基础帧：

- 人物从一个位置移动到另一个位置；
- 人物仍然是同一种可见面，例如上一帧是背影，当前帧仍然是背影；
- 镜头尺度没有显著变化，例如 wide shot 继续 wide shot，或 medium shot 继续 medium shot；
- 场景、光源、人物服装、人物比例基本稳定；
- 当前目标是继承上一帧的构图距离和人物朝向，而不是重新展示角色细节。

推荐写法：

```text
Use case_base_frame01.png for the cultivator's character identity, current back-view robe silhouette, black high ponytail, library layout, moonlight direction, stone floor texture, bookshelf positions, central table outline, and the overall shot distance.
```

#### 需要重新引用 `case_char_01.png` 的情况

只有当当前帧发生以下变化时，才建议重新引入角色参考图：

- 从背影切到正面，或从正面切到背影；
- 人物可见面发生明显变化，需要重新确认脸部、发型或服装细节；
- 镜头从 wide shot 变为 medium shot，且人物细节明显放大；
- 上一帧人物身份、发型、服装已经漂移；
- 当前帧有显著姿态变化，上一帧不足以提供稳定人物信息；
- 当前帧需要清楚展示正脸、胸前服饰、手部细节或配饰。

核心原则：

```text
基础帧优先继承上一帧的剧情状态、镜头尺度、人物可见面和场景锚点；只有在身份校正或可见面显著变化时，才重新引用角色图。
```

### 6.2 基础帧 Prompt 最小模板

```text
Generate case_base_frame0x.png: Use [one real filename, preferably the previous base frame when it already contains stable identity, scene, shot scale, and orientation] for [specific inherited identity, visible body side, scene anchors, lighting, object state, and shot distance]. If needed, also use [case_char_01.png or another real filename] for [only the missing or drifting identity details]. Camera: [wide shot or medium shot must be replaced by one confirmed shot type], [viewpoint], [stable composition focus], [front view / back view / side view / three-quarter view must be explicitly stated]. The main subject is [character] positioned at [concrete anchor-based location], with [subject-object relation] and [subject-camera relation]. Clearly show [visible body details appropriate to this base shot], [concrete spatial relation], and [object or environment state]. If the character's face should not appear, explicitly state which facial structures are not visible. Keep [identity, outfit, lighting, scene layout, shot scale, and important anchors] unchanged. Do not add [unwanted objects, extra characters, wrong effects, wrong camera side, or complex camera changes]. Cinematic Chinese fantasy 3D animation style.
```

注意：模板中的 `[wide shot or medium shot must be replaced by one confirmed shot type]` 只是说明，最终 prompt 中必须替换成 `wide shot` 或 `medium shot` 中的一个，不能保留选择式表达。

## 7. 第一阶段候选选择规则

当用户上传同一基础帧的多个候选图时，模型必须先执行基础帧候选选择。

### 7.1 基础帧选择优先级

1. **Story State Accuracy**：是否准确表现当前剧情节点；
2. **Base Camera Accuracy**：是否符合指定的 `wide shot` 或 `medium shot`；
3. **Subject–Camera Accuracy**：人物相对镜头的正面、背面、侧面或三分之二视角是否正确；
4. **Opening Orientation Reasonableness**：如果是 `case_base_frame01.png`，朝向是否服务于开场镜头意图，而不是机械默认背影或正面；
5. **Subject–Object Accuracy**：人物是否正确面向、背向、侧对或接触目标物；
6. **Anchor Accuracy**：人物、道具是否落在指定场景锚点；
7. **Reference Stability**：候选图是否继承了上一帧的镜头尺度、人物比例和可见面；
8. **Character Consistency**：人物身份、发型、服装、体型是否稳定；
9. **Scene Continuity**：场景结构、光源、关键物体是否继承；
10. **Object State Continuity**：道具或环境状态是否正确；
11. **Editability**：是否适合作为第二阶段再编辑输入；
12. **Visual Quality**：是否清晰、无畸形、无错误元素。

### 7.2 基础帧候选选择输出模板

```md

下一帧进入“……”。

Generate case_base_frame04.png: ...
```

## 8. 第二阶段：全帧再编辑规划规则

第二阶段是 v6.3 的核心升级。

### 8.1 不再选择“是否变换”，而是选择“如何编辑”

v6.2 中，第二阶段由多模态大模型选择哪些基础帧需要镜头变换，未选中的基础帧直接进入最终分镜。

v6.3 中，所有基础帧都必须进入再编辑：

```text
case_base_frame01.png → case_edit_frame01.png
case_base_frame02.png → case_edit_frame02.png
case_base_frame03.png → case_edit_frame03.png
...
case_base_frame09.png → case_edit_frame09.png
```

多模态大模型需要为每一帧决定：

- 编辑目标；
- 编辑强度；
- 镜头策略；
- 需要修复的瑕疵；
- 必须保持不变的剧情状态；
- 最终画面重点。

### 8.2 编辑强度分级

第二阶段每一帧都要编辑，但编辑强度不同。

#### Level 1：Continuity-preserving cleanup

适合基础帧已经很稳定，只需要轻微修瑕和统一风格。

可做：

- 修正轻微手部、衣摆、发丝、道具边缘；
- 强化角色轮廓；
- 稳定光照和色调；
- 清理杂乱背景；
- 保持原镜头和构图。

不做：

- 改变人物位置；
- 改变人物朝向；
- 改变景别；
- 改变道具状态。

#### Level 2：Cinematic polish

适合基础帧构图正确但画面表现力不足。

可做：

- 调整构图重心；
- 增强前景、中景、背景层次；
- 强化光影和氛围；
- 让人物、道具或环境重点更清楚；
- 保持原来的 wide shot 或 medium shot。

#### Level 3：Moderate camera reframe

适合当前帧需要更强电影感，但仍要保留大部分空间关系。

可做：

- wide shot 改为 stronger wide shot；
- medium shot 改为 medium close-up；
- 改为三分之二侧面；
- 增加轻微低角度或高角度；
- 强化主体比例。

注意：

- 仍必须保持剧情状态；
- 不能变成完全不同的场景；
- 不能让人物动作进入下一帧。

#### Level 4：Strong cinematic transformation

适合关键动作、关键道具、高潮或结果帧。

可做：

- close-up；
- insert shot；
- overhead view；
- low-angle view；
- over-the-shoulder view；
- foreground framing；
- dramatic but controlled camera composition。

注意：

- 只适合剧情关键帧；
- 不能全九帧都使用强变换；
- 强变换帧必须能从 base frame 继承核心剧情状态。

### 8.3 基础帧瑕疵分级

第二阶段可以修复轻微瑕疵，但不能用编辑掩盖严重错误。

#### 可通过第二阶段修复的轻微瑕疵

- 人物手指轻微不自然；
- 衣摆、袖口、发丝局部异常；
- 道具不够清楚但存在；
- 光线偏弱或氛围不足；
- 构图略平；
- 背景细节稍乱；
- 人物占比略不理想；
- 目标物需要更突出；
- 面部细节需要轻微稳定；
- 镜头电影感不足。

#### 需要重生成基础帧的严重错误

- 人物身份明显错误；
- 场景变成另一个地点；
- 关键道具完全缺失；
- 当前剧情节点错误；
- 人物位置与锚点严重不符；
- 人物朝向与剧情关系完全错误；
- 道具状态提前或滞后到其他帧；
- 多出重要无关人物；
- 画面严重畸形；
- 基础帧无法看出应有剧情状态。

核心原则：

```text
轻微瑕疵进入第二阶段修复；严重剧情错误必须先重生成 base frame。
```

### 8.5 镜头多样性预算

虽然所有帧都要编辑，但不代表每一帧都要强行使用复杂镜头。

推荐 9 宫格最终镜头结构：

- 2–3 帧保留或强化 wide shot，用于空间交代和收束；
- 2–3 帧使用 medium / medium close-up，用于人物动作；
- 1–2 帧使用 insert shot，用于手、道具、接触点；
- 1 帧使用 overhead / high-angle，用于空间能量或布局；
- 1 帧使用 low-angle / over-the-shoulder，用于高潮或凝视目标物。

不推荐：

- 九帧全部 close-up；
- 九帧全部低角度；
- 九帧全部过肩；
- 为了多样性牺牲剧情阅读；
- 每帧都大幅改变视角导致空间关系断裂。

核心原则：

```text
所有帧都要再编辑，但不是所有帧都要强变换。编辑强度由剧情功能、基础帧质量和最终九宫格节奏共同决定。
```

## 10. 第二阶段候选选择规则

当用户上传同一编辑帧的多个候选图时，模型必须选择最适合作为最终分镜帧的图。

### 10.1 编辑帧候选选择优先级

1. **Story State Preservation**：是否保持对应 base frame 的剧情状态；
2. **Continuity with Base Frame**：是否能看出来自对应基础帧；
3. **Defect Correction Quality**：是否修复或改善了基础帧中的轻微瑕疵；
4. **Camera Strategy Accuracy**：是否实现了规划中的编辑镜头策略；
5. **Character Consistency**：人物身份、服装、发型是否一致；
6. **Object State Preservation**：道具或环境状态是否没有被错误改变；
7. **Orientation Accuracy**：人物与镜头、人物与目标物关系是否正确；
8. **Visible Detail Quality**：当前镜头应该强调的细节是否清楚；
9. **Final Storyboard Rhythm**：与前后 edited frames 放在一起是否有节奏变化；
10. **Visual Quality**：是否清晰、无畸形、无错误元素。

### 10.2 编辑帧候选选择输出模板


## 12. 位置锚点定位规则

位置锚点规则在两个阶段都必须使用。

### 12.1 必须使用场景内可见锚点

当 prompt 描述人物或道具位置时，优先使用场景图、基础帧或编辑帧中已经存在、视觉明确的锚点。

推荐：

```text
The figure stands at the center of the multi-ringed circular texture on the stone platform.
```

```text
The character stands just behind the front edge stones of the circular platform, aligned with the center ring pattern.
```

```text
The jade scroll lies on the empty wooden surface between the brush holder and the red seal, above the front edge of the table.
```

不推荐：

```text
The character stands in the center of the platform.
```

```text
The object is on the right side of the table.
```

```text
The figure stands near the pillar.
```

### 12.2 再编辑阶段也必须保留锚点

第二阶段不能因为镜头电影化而丢失关键锚点。即使是特写或插入镜头，也应保留足够的局部锚点，例如：

- 桌面木纹；
- 玉简与手指接触点；
- 袖口颜色；
- 地面纹理；
- 平台圆环纹理；
- 石柱底座边缘；
- 光纹扩散方向。

核心原则：

```text
基础帧用锚点锁剧情；编辑帧用锚点保连续。
```

### 12.3 不用 distance，用可见关系

控制人物与目标物远近时，禁止只写：

```text
closer to the pillar
farther from the pillar
reduced distance
near the object
move two steps forward
```

应写最终画面中的可见关系：

```text
The front boot is on the narrow stone band immediately around the circular pillar base.
```

```text
The boot toe almost touches the outer edge of the pillar base.
```

```text
No complete cobblestone ring is visible between the front boot and the pillar base.
```

## 13. 朝向关系规则

写每一帧 prompt 前，必须先判断两个关系：

1. **Subject–Object Relation**：人物面向目标物、背向目标物、侧对目标物，还是正在接触目标物；
2. **Subject–Camera Relation**：人物面向镜头、背对镜头、侧对镜头，还是过肩、俯视或局部。

这两个关系决定 prompt 应描述哪些身体细节，不能混写。

### 13.1 人物面向镜头时

可以描述：

- facial structure；
- eyes；
- gaze；
- front robe pattern；
- collar；
- chest；
- belt；
- sleeves；
- hands in front of the body。

### 13.2 人物背对镜头时

必须避免：

- facial structure；
- facial expression；
- calm face；
- eyes closed；
- focused expression；
- handsome face；
- looking at the camera。

应描述：

- back of hairstyle；
- back of head；
- shoulder line；
- back-view robe folds；
- waist belt from behind；
- sleeves from behind；
- boots；
- stable stance；
- target object in front of him。

### 13.3 再编辑阶段的朝向规则

第二阶段可以改变镜头角度，但不能随意改变人物与目标物关系。

例如：

- base frame 中人物面向桌面玉简，edited frame 可以从正面、侧面或过肩展示；
- 但不能让人物变成背向玉简；
- 不能让人物动作从“未触碰”变成“已经拿起”；
- 不能让人物从桌前移动到窗边；
- 不能让镜头重构改变剧情状态。

核心原则：

```text
镜头可以变，剧情状态不能变；相机位置可以变，人物与目标物的关系不能乱变。
```

## 14. Camera Layer 规则

每一帧 prompt 必须包含 camera layer。

### 14.1 第一阶段 Camera Layer

第一阶段只允许明确使用：

```text
Camera: wide shot, ...
```

或：

```text
Camera: medium shot, ...
```

第一阶段禁止使用不确定表达：

```text
wide shot or medium shot
wide / medium shot
suitable camera distance
appropriate shot size
```

### 14.2 第二阶段 Camera Layer

第二阶段允许使用：

```text
wide shot
medium shot
medium close-up
close-up
insert shot
eye-level view
low-angle view
high-angle view
overhead view
over-the-shoulder view
back view
side view
foreground framing
```

但不能只写镜头术语，必须写清楚当前镜头下的可见内容。

推荐：

```text
Camera: insert shot, slightly high-angle view, the fingertips, sleeve cuffs, and glowing object surface fill most of the frame.
```

不推荐：

```text
Camera: insert shot.
```

### 14.3 镜头变换不改变剧情

第二阶段可以改变视角、景别、构图重点，但不能改变：

- 人物身份；
- 人物最终位置；
- 人物动作结果；
- 道具状态；
- 场景结构；
- 光源方向；
- 已经建立的剧情节点。

## 15. 禁止误导词规则

以下词在两个阶段都应尽量避免。

### 15.1 抽象距离词

不推荐：

```text
closer
farther
near
reduced distance
increased distance
```

推荐：

```text
front boot on the narrow stone band around the pillar base
```

```text
boot toe almost touching the outer edge of the pillar base
```

```text
several full cobblestone rings visible between the boots and the pillar base
```

### 15.2 模糊程度词

不推荐：

```text
slightly
subtly
a little
partially visible
```

推荐：

```text
only the back of the head and right shoulder are visible
```

```text
the eyes, nose, mouth, and side face are not visible
```

### 15.3 第一阶段选择式镜头词

基础帧 prompt 中禁止：

```text
wide shot or medium shot
wide / medium shot
either wide shot or medium shot
a suitable full or medium view
```

必须改成：

```text
Camera: wide shot, ...
```

或：

```text
Camera: medium shot, ...
```

### 15.4 再编辑阶段禁止词

第二阶段再编辑 prompt 中应避免：

```text
redesign the whole scene
create a new version of the scene
change the story
make a new pose
move the character
different object state
new location
```

推荐使用：

```text
re-edit the same moment
preserve the exact story state
keep the character position unchanged
keep the object state unchanged
improve the cinematic composition
clean up minor defects
```

## 17. 两阶段质检规则

### 17.1 第一阶段基础帧质检

检查：

- 是否使用唯一确定的 `wide shot` 或 `medium shot`；
- prompt 是否出现 `or`、`either`、`/` 这类选择式镜头表达；
- prompt 是否显式写明人物与镜头关系，例如 back view、front view、side view 或 three-quarter view；
- 如果是 `case_base_frame01.png`，是否写明开场镜头意图和朝向选择理由；
- 如果是 `case_base_frame01.png`，是否避免机械默认背影开场；
- prompt 是否只写了人物面向目标物，却没有写人物面向镜头还是背对镜头；
- 当前帧是否遵循最小参考原则；
- 人物是否落在指定场景锚点；
- 人物全身或主要身体结构是否足够清楚；
- 场景结构是否完整稳定；
- 角色身份是否一致；
- 道具状态是否承接；
- 当前帧是否适合作为第二阶段再编辑输入。

### 17.2 第二阶段编辑帧质检

检查：

- 是否从正确的 `case_base_frame0x.png` 再编辑；
- 是否保留基础帧的剧情状态；
- 是否保留人物身份、服装、发型；
- 是否保留道具状态和环境状态；
- 是否实现规划中的编辑策略；
- 是否修复或改善了基础帧中的轻微瑕疵；
- 镜头下应该可见的细节是否清楚；
- 镜头下不应该出现的结构是否没有出现；
- 是否与前后 edited frames 保持节奏和连续性；
- 是否比基础帧更适合作为最终电影镜头。

## 18. 重生成判定

### 18.1 基础帧需要重生成的情况

出现以下情况，应重生成基础帧：

- prompt 中使用了不确定镜头表达；
- prompt 没有显式写明人物与镜头关系；
- `case_base_frame01.png` 机械默认背影开场，且该 idea 更适合人物介绍、桌面线索展示或正面氛围开场；
- 候选图中人物应背对镜头却变成正对镜头，或应侧对镜头却变成正面展示；
- 当前帧只是连续移动，却不必要地引用 `case_char_01.png` 并导致镜头拉近、人物转正或构图改变；
- 画面不是指定的 `wide shot` 或 `medium shot`；
- 人物位置没有对齐场景锚点；
- 人物身份、服装、发型明显变化；
- 场景结构被错误改变；
- 道具状态不符合剧情；
- 人物朝向与目标物关系错误；
- 当前帧镜头过于复杂，不适合作为再编辑输入；
- 基础帧人物与镜头关系错误，尤其是应为背影却露出正脸；
- 基础帧参考图选择不合理，导致本应继承上一帧的镜头尺度和朝向被破坏。

### 18.2 编辑帧需要重生成的情况

出现以下情况，应重生成编辑帧：

- 再编辑没有保留基础帧的剧情状态；
- 再编辑后人物位置变化；
- 再编辑后道具状态变化；
- 再编辑后角色身份不一致；
- 再编辑后场景变成另一个地点；
- 规划中的镜头策略没有实现；
- 特写或局部镜头没有展示该镜头应有的细节；
- 背面或过肩镜头错误露出正脸；
- 新增无关角色、武器、道具或环境效果；
- 为了电影感过度重构，导致与前后帧不连续。

### 18.3 允许保留 base frame 的异常情况

标准流程中最终帧应来自 `case_edit_frame0x.png`。  
只有在以下情况下，允许保留对应 base frame 作为最终帧：

- 多次再编辑均破坏剧情状态；
- base frame 本身已经视觉质量很高；
- edited frame 无法稳定保持人物、道具或场景；
- 用户明确要求保留 base frame。

此时必须在最终整理表中说明原因。

## 19. 核心执行口令

### 19.1 第一阶段基础帧生成前必须先问

1. What is the story beat of this base frame?
2. Is this base frame a wide shot or a medium shot?
3. If this is case_base_frame01.png, what is the opening intent: character introduction, spatial introduction, entrance action, key object introduction, or suspense?
4. If this is case_base_frame01.png, which orientation best serves that opening intent: front view, three-quarter front view, side view, back view, or three-quarter back view?
5. Is the selected shot type written as one confirmed camera choice?
6. What real filenames should be referenced?
7. What specific anchors should be inherited from each file?
8. What scene anchor locates the character or object?
9. What is the final visible position, not the movement process?
10. What is the subject-object relation?
11. What is the subject-camera relation?
12. What should remain visible for future editing?
13. Does this frame avoid close-up, insert shot, overhead view, over-the-shoulder view, and complex camera rotation?
14. Does this frame provide a stable input for full-frame re-editing?

### 19.2 第二阶段全帧再编辑前必须先问

1. Does this base frame contain a severe story error that requires base regeneration?
2. What minor defects can be corrected during re-editing?
3. What edit strength should be used: Level 1, Level 2, Level 3, or Level 4?
4. What camera strategy best serves this frame in the final storyboard?
5. What exact story state must be preserved from the base frame?
6. What visible details should the edited frame emphasize?
7. What spatial anchors must remain visible?
8. What character identity details must remain consistent?
9. What object state must remain unchanged?
10. What structures should not appear in this edited shot?
11. Does this edit improve the final storyboard without changing the story?
12. Does the edited frame maintain rhythm with the previous and next edited frames?

## 20. 一句话总结

v6.3 的核心不是“只挑几帧做镜头变化”，而是：

```text
First generate stable base frames to lock story continuity, then re-edit every base frame to fix minor defects, unify cinematic quality, and assign an appropriate camera strategy to each final frame.
```

中文概括：

```text
先用明确全景或明确中景生成稳定剧情骨架，再对所有基础帧逐帧再编辑；基础帧负责锁定连续性，编辑帧负责修复瑕疵、统一电影质感并增加镜头多样性。
```
